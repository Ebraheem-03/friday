- **[SEC] WebAgent action-level gate (scout Step 7):** browser-use 0.13.1 does not expose a per-action callback; the task-prefix LLM instruction is the only gate against state-changing actions. - **[SEC] WebAgent SSRF domain filter (scout Step 7):** browser-use can navigate to any URL including `localhost`, `10.x`, `192.168.x`. Add a domain allowlist/denylist to block internal addresses.
- **[SEC] WebAgent hard timeout (scout Step 7):** `agent.run()` has no wall-clock timeout. Add `asyncio.wait_for()` wrapper with a configurable cap (default: 120s) to prevent runaway automation.
- **[SEC] WebAgent browser-use internal logging audit (scout Step 7):** browser-use may log `extracted_content`, screenshots, or page text internally at INFO level — sentinel confirmed `agent/service.py:_log_agent_run` logs `Task: {task}` at INFO (library's own logger, not FRIDAY's). - **[SEC] browser-use version-check phone-home (sentinel Step 7, LOW):** `BROWSER_USE_VERSION_CHECK` defaults True → async HTTP GET to `https://pypi.org/pypi/browser-use/json` on every `agent.run()`. Not telemetry but uninvited egress. Suppress via `BROWSER_USE_VERSION_CHECK=false`; add to `.env.example`.
- **[SEC] OS bridge `type`/`click` ungated (sentinel M-1, Step 6):** synthetic-input actions execute even in dry_run mode (only `run_command` is gated). Prompt-injection risk: keystrokes into a focused terminal, clicking destructive UI. Decide whether to extend the confirm/dry-run gate to `type`/`click` (security) vs. leave ungated (usability). atlas recommendation: gate them, with a human-set "trusted/unattended" mode to relax.
- **[SEC] OS bridge default confirm callback logs full argv at WARNING (sentinel M-2, Step 6):** secrets passed as CLI args could leak to logs once a real confirm prompt is built; log binary name only.
- **[SEC] OS bridge `read_file` sensitive-path blocklist non-exhaustive (sentinel L-1, Step 6):** add `~/.ssh`, `/etc/ssl/private`, etc.; OS perms are the real guard.
- **[SEC] Telemetry WS no-auth localhost socket (sentinel Step 8a, LOW):** any local process can connect to 127.0.0.1:<port> and read state+cpu+ram. Acceptable while the frame carries only non-sensitive metrics. IF the frame ever gains sensitive fields (transcript text, file paths being acted on), add a shared-token handshake or switch to a unix socket.
